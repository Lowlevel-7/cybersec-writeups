# WiFi Hacking 101

## Platform
TryHackMe

## Objective
Learn the fundamentals of WiFi security, WPA authentication,
packet capture, Aircrack-ng, and password auditing in an
authorized lab environment.

## Topics Covered

- WiFi and WPA basics
- Monitor mode
- Packet capture
- Handshakes
- Aircrack-ng
- Wordlist-based password cracking
- Wireless security concepts

## Tools Used

- Aircrack-ng
- Airodump-ng
- Aireplay-ng
- iwconfig / iw
- Wireshark
